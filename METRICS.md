# Metrics

The North Star metric is qualified audits completed per week. A qualified audit means the user entered at least two tools or more than $100/month of AI spend and reached the results page. This fits the product because StackTrim is not a daily-use app; the valuable behavior is a serious buyer or operator trusting the tool enough to submit real spend and see recommendations.

Three input metrics drive the North Star. First, visitor-to-form-start rate shows whether the landing copy matches the pain. Second, form-start-to-audit-complete rate shows whether the input flow is too heavy or confusing. Third, high-savings-audit-to-email-capture rate shows whether the results page creates enough trust to start a Credex relationship.

I would instrument page view, form started, tool added or edited, audit submitted, audit completed, public report viewed, email captured, share link copied, and Credex consultation clicked. I would also store anonymized stack shape fields such as use case, tool count, total spend bucket, and savings bucket so Credex can learn which segments have the strongest economics.

The pivot trigger is fewer than 20 qualified audits from 1,000 targeted visitors or less than 15% email capture on audits with more than $500/month savings. If that happens, either the pain is not urgent, the trust gap is too large, or the tool should move from self-serve audit to concierge teardown.
